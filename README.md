# 🌌 A Origem de Tudo: Uma Jornada Pelo Big Bang

## 📒 Descrição
Este projeto é uma apresentação interativa que explora a criação do universo sob a perspectiva da teoria do Big Bang. Criada com ferramentas de IA generativa, a apresentação busca visualizar e explicar de forma envolvente os eventos que moldaram a existência do cosmos.

## 🤖 Tecnologias Utilizadas
🔹 Gamma AI – Para a criação e formatação da apresentação interativa;
[🔗Gamma](https://gamma.app)

🔹 Leonardo AI – Para gerar imagens que ilustram momentos-chave da origem do universo;
[🔗Leonardo.Ai](https://leonardo.ai/ai-art-generator/)

🔹 ChatGPT – Para estruturar o README e auxiliar na organização do conteúdo.
[🔗Chat GPT](https://chatgpt.com/)

## 🧐 Processo de Criação
1. Ideia inicial 💡: Concebi o projeto como uma apresentação visualmente envolvente sobre o Big Bang;
2. Gamma AI 🎨: Usei essa ferramenta para estruturar os slides e adicionar elementos interativos;
3. Leonardo AI 🌠: Criei imagens personalizadas para ilustrar a expansão do universo e os eventos cósmicos;
4. ChatGPT 📝: Auxiliou na organização do conteúdo e refinamento do README.

## 🚀 Resultados
O projeto resultou em uma apresentação dinâmica e visualmente impactante, combinando informações científicas com imagens geradas por IA para tornar o conceito do Big Bang mais acessível e cativante. Confira a apresentação aqui:

[🔗A Origem de Tudo: Big Bang](https://gamma.app/docs/A-Origem-de-Tudo-Uma-Jornada-Pelo-Big-Bang-0kr46tnpirlbywi)
